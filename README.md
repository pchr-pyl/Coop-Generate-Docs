# ระบบสร้างหนังสือขอความอนุเคราะห์ (Mail Merge PDF)

ระบบเว็บแอปพลิเคชันสำหรับสร้างหนังสือขอความอนุเคราะห์จากไฟล์ Excel โดยใช้เทคนิค Mail Merge กับไฟล์ PDF

## ฟีเจอร์หลัก

- 📥 **ดาวน์โหลดเทมเพลต Excel** - เทมเพลตพร้อมคอลัมน์ที่จำเป็น
- 📤 **อัปโหลดไฟล์ Excel** - รองรับไฟล์ .xlsx ที่กรอกข้อมูลแล้ว
- 📄 **สร้าง PDF อัตโนมัติ** - แทนที่ข้อมูลใน PDF template ตามข้อมูลจาก Excel
- 📦 **รวมเป็นไฟล์ ZIP** - บีบอัดไฟล์ PDF ทั้งหมดเพื่อดาวน์โหลดครั้งเดียว
- 🇹🇭 **รองรับภาษาไทย** - ใช้ฟอนต์ TH Sarabun New

## การติดตั้งและรัน

### 1. ติดตั้ง Dependencies

```bash
pip install -r requirements.txt
```

### 2. เตรียมฟอนต์ภาษาไทย

ดาวน์โหลดฟอนต์ TH Sarabun New และวางไว้ในโฟลเดอร์โปรเจกต์:
- ดาวน์โหลดจาก: https://www.f0nt.com/release/th-sarabun/
- วางไฟล์ `THSarabunNew.ttf` ในโฟลเดอร์หลักของโปรเจกต์

### 3. รันแอปพลิเคชัน

```bash
python app.py
```

เข้าใช้งานที่: http://localhost:5000

## วิธีใช้งาน

### ขั้นตอนที่ 1: ดาวน์โหลดเทมเพลต
1. คลิกปุ่ม "ดาวน์โหลดเทมเพลต Excel"
2. กรอกข้อมูลในไฟล์ Excel ตามคอลัมน์:
   - **ชื่อ-สกุล นักศึกษา**: ชื่อเต็มของนักศึกษา
   - **เรียน**: ตำแหน่งผู้รับเช่น "ผู้อำนวยการ", "ผู้จัดการฝ่ายทรัพยากรบุคคล"
   - **สถานประกอบการ**: ชื่อบริษัทหรือหน่วยงาน

### ขั้นตอนที่ 2: อัปโหลดไฟล์
1. คลิกหรือลากไฟล์ Excel ที่กรอกข้อมูลแล้ว
2. ตรวจสอบชื่อไฟล์ที่แสดง
3. คลิก "สร้างไฟล์ PDF"

### ขั้นตอนที่ 3: ดาวน์โหลดผลลัพธ์
- ระบบจะสร้างไฟล์ PDF แยกตามชื่อสถานประกอบการ
- รวบรวมทั้งหมดในไฟล์ ZIP พร้อมดาวน์โหลด

## เทคโนโลยีที่ใช้

- **Flask** - Web framework
- **Pandas** - จัดการไฟล์ Excel
- **PyMuPDF** - ประมวลผลไฟล์ PDF
- **ReportLab** - สร้างและแก้ไข PDF
- **Bootstrap 5** - UI framework

## การปรับแต่ง

### การเปลี่ยน PDF Template
ปัจจุบันระบบสร้าง PDF แบบง่าย หากต้องการใช้ PDF template ที่ซับซ้อน:
1. วางไฟล์ PDF template ในโฟลเดอร์ `templates/`
2. แก้ไขฟังก์ชัน `generate_single_pdf()` ใน `app.py`

### การเพิ่มฟิลด์ใหม่
1. แก้ไข Excel template ในฟังก์ชัน `download_template()`
2. เพิ่มการตรวจสอบคอลัมน์ในฟังก์ชัน `upload_file()`
3. แก้ไขการสร้าง PDF ในฟังก์ชัน `generate_single_pdf()`

## ข้อจำกัดและข้อควรรู้

- รองรับไฟล์ Excel เฉพาะ .xlsx
- ขนาดไฟล์สูงสุด: 16MB
- ต้องมีฟอนต์ TH Sarabun New สำหรับการแสดงผลภาษาไทยที่ถูกต้อง
- ชื่อไฟล์ PDF จะตั้งตามชื่อสถานประกอบการ (ตัดอักขระพิเศษออก)

## การแก้ไขปัญหา

### ฟอนต์ภาษาไทยไม่แสดงผล
- ตรวจสอบว่ามีไฟล์ `THSarabunNew.ttf` ในโฟลเดอร์โปรเจกต์
- รีสตาร์ทแอปพลิเคชันหลังเพิ่มฟอนต์

### ข้อผิดพลาดเมื่ออัปโหลดไฟล์
- ตรวจสอบว่าไฟล์เป็น .xlsx และมีคอลัมน์ที่จำเป็นครบถ้วน
- ตรวจสอบขนาดไฟล์ไม่เกิน 16MB

### ไฟล์ PDF ไม่ถูกต้อง
- ตรวจสอบข้อมูลใน Excel ว่าไม่มีช่องว่างหรืออักขระพิเศษที่อาจทำให้เกิดข้อผิดพลาด
